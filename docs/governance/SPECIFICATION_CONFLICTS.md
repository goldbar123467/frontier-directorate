resolved for Gate Zero; none remains an internal blocker to Update 01.

## Change discipline

Any discovered contradiction is registered before implementation proceeds. A
resolution must state affected requirement IDs, update specifications, tests,
save/replay implications, and whether already verified updates become
`REGRESSION`. “Defer and hope” is not a resolution.
